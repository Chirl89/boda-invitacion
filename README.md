# 💌 Invitación Digital de Boda

Web interactiva de invitación de boda con confirmación de asistencia (RSVP), cuenta atrás, cronograma, mapas interactivos, recomendaciones y música de fondo.

## ✨ Características
- **Diseño Responsive & Elegante**: Adaptado a móviles y tablets con tipografía refinada y animaciones suaves.
- **Cuenta atrás interactiva**: Días, horas, minutos y segundos hasta el gran día.
- **Detalles del evento**: Ubicación de ceremonia y banquete con botones directos a Google Maps.
- **Confirmación RSVP**: Formulario conectado directamente con Google Sheets en tiempo real.
- **Música ambiental**: Reproductor discreto con control táctil.
- **Preguntas Frecuentes y Dress Code**: Toda la información que los invitados necesitan.

## 🚀 Publicación en GitHub Pages (Gratis)
1. Ve a la pestaña **Settings** de este repositorio en GitHub.
2. En la barra lateral izquierda, entra en **Pages**.
3. En **Build and deployment > Branch**, selecciona la rama main y la carpeta / (root).
4. Haz clic en **Save**. En 1-2 minutos tendrás la URL pública activa para compartir con tus invitados.
